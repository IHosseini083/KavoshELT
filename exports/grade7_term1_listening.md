## بخش اول: برگه سوالات دانش‌آموز (Student's Question Sheet)

### **Part A: True / False (Questions 1 - 5) — [2.5 Points]**
> **دانش‌آموز عزیز، به مکالمه بین «علی» و «معلم» گوش دهید و مشخص کنید جملات زیر درست (True) هستند یا نادرست (False). (هر سوال ۰.۵ نمره)**

1. The student's first name is Ali. ( **True** / **False** )
2. Ali's last name is Rezaei. ( **True** / **False** )
3. Ali is twelve years old. ( **True** / **False** )
4. Ali's father is a dentist. ( **True** / **False** )
5. Ali's mother is a kind teacher. ( **True** / **False** )
